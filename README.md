# QUAD LAB

중학교 2학년 학생이 SVG 도형을 직접 움직이며 **사각형의 성질**을 발견하는 정적 웹 학습 앱입니다.

## 선생님 검토용 개발 버전

현재 개발 작업은 `quad-lab-refresh` 브랜치에만 반영되어 있습니다. 공개 GitHub Pages 사이트는 `main` 브랜치의 기존 버전이며, 이 개발 버전을 자동으로 보여 주지 않습니다.

1. [개발 브랜치 열기](https://github.com/yjh0115/YANG/tree/quad-lab-refresh)에서 **Code → Download ZIP**을 선택합니다. 반드시 브랜치 표시가 `quad-lab-refresh`인지 확인하세요.
2. ZIP 압축을 풀고 `index.html`을 열어 화면을 살펴볼 수 있습니다. 다만 브라우저의 로컬 파일 보안 정책에 따라 일부 기능이 제한될 수 있으므로, 기능 검증에는 아래 정적 서버 방식을 권장합니다.
3. `index.html`에서 6개 탐구를 확인하고, `relation-map.html`에서 포함 관계 지도를, `master-mission.html`에서 최종 미션을 확인하세요.

`quad-lab-preview.html`은 이전에 만든 단일 HTML 미리보기 파일로, 최신 개발 브랜치의 여러 파일로 나뉜 수정 사항을 모두 포함한다고 보장할 수 없습니다. **최신 버전 검토에는 `index.html`을 사용하세요.**

## 권장 실행 방법

별도 빌드나 패키지 설치는 필요하지 않습니다. 압축을 푼 폴더에서 터미널을 열고 다음 명령으로 정적 파일 서버를 실행합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 <http://localhost:4173>을 엽니다. Python이 설치되어 있지 않으면 정적 파일 서버를 제공하는 다른 개발 도구를 이용해도 됩니다.

## 주요 기능

- 평행사변형, 직사각형, 마름모, 정사각형의 실시간 SVG 조작 및 좌표 기반 측정
- `탐구 → 발견 → 개념 정리 → 연습 → 도전 문제 → 학습 완료`의 단계형 학습
- 평행사변형 조건 드래그 분류와 사각형 포함 관계 다이어그램
- 오답 시 단계형 힌트를 제공하는 차시별 문제
- 10문항 최종 미션과 영역별 이해도 결과
- `localStorage` 기반 진도 및 결과 저장

실제 브라우저 및 화면 읽기 프로그램 검증 결과는 [QA 점검표](QA-CHECKLIST.md)에 별도로 기록해야 합니다. 소스 파일을 읽거나 GitHub에 저장한 것만으로 작동 테스트를 통과했다고 판단하지 않습니다.
